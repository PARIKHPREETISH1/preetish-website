# Marketing Analytics Coursework | Experiments, Models & Machine Learning
- https://parikhpreetish1.github.io/preetish-website/

This repository contains a series of marketing analytics assignments completed as part of a graduate-level coursework. Each assignment was written and published as a semi-professional blog post using Quarto and deployed on a personal website via GitHub Pages.

## Project Overview
The projects replicate academic research and apply statistical and machine learning methods to real-world marketing datasets. Emphasis was placed on clear storytelling, well-formatted visualizations, and interpretable model results.

## Key Topics & Methods
- A/B Testing and causal inference using experimental donation data  
- Maximum Likelihood Estimation with Poisson regression models  
- Multinomial Logit (MNL) models for conjoint analysis using both MLE and Bayesian methods  
- Unsupervised learning using custom implementations of K-means clustering or Latent Class MNL  
- Supervised learning using K-Nearest Neighbors (KNN) and key driver analysis  

## Tools & Technologies
- R, Quarto (.qmd)
- GitHub Pages for web deployment
- Custom model implementation alongside built-in statistical functions

## Output
Each assignment is rendered as a blog-style article and published on my personal website to demonstrate applied analytics, modeling rigor, and technical communication skills.
